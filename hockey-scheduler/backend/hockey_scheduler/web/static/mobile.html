Calendar-first Operator Demo

Run a league & arena from one app, driving the real backend — every create and schedule action hits the API.

  1. Setup — create a league, season, division, club, team, venue, rink (real records).
  2. Calendar — see ice by rink & time; tap an Available slot → Schedule Game wizard.
  3. Games — the operations checklist per game; open the roster.
  4. Roster — Coach/Player substitute flow: back out → open slot → enroll → add → confirm → lock.
  5. Public — fan fixtures, no junior player names.

Officials, results, notifications & calendar export are shown as disabled follow-ups linked to their issues.
