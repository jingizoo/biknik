Full E2E Demo

One browser walkthrough of the whole hockey operating flow, driving the real backend: League → Arena → Schedule → Game → Substitute → Public.

  1. League & Arena — the seeded Alpine league, divisions, clubs, teams, venue, rinks and ice slots.
  2. Schedule — the manual game created from the setup layer; tap Open.
  3. Game — Coach marks a skater Can't play → Open Slot; a player enrolls → Needs Substitute; Coach adds → Confirmed; then Lock Roster.
  4. Activity — the notification + audit trail.
  5. Public — the fan fixture page (no junior player names).

Reset restores the confirmed roster. Officials, results, notifications and calendar feeds are shown as disabled follow-ups.
