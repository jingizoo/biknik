Hockey Scheduler — Game Detail

This is a browser preview of the iPhone screen. It drives the real roster & substitute engine from the backend.

  1. In Coach view, mark a selected skater Can't play → watch the status flip to Open Slot.
  2. Switch to Player view, pick an un-selected player, tap Enroll as Substitute.
  3. Back in Coach view, Add that substitute → the slot closes and the roster is confirmed again.

Reset returns to a fully confirmed roster.
